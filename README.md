# RC Setup Hub

Go/PostgreSQL backend and server-rendered admin for storing and sharing RC drift
setups. The React client lives in [rc-setup-hub-fe](https://github.com/BlinovDev/rc-setup-hub-fe).

- [Local setup](backend/README.md): database, configuration, migrations and server.
- [AGENTS](AGENTS.md): task-aware context and coding-agent boundaries.
- [Product](AI/product.md): current shared business rules.
- [API](AI/api.md) and [OpenAPI](backend/api/openapi.yaml): transport contract.
- [Testing](AI/testing.md): commands, prerequisites and evidence limits.
- [Workflow](AI/workflow.md): scope, docs by exception and PR/release gates.
- [Deployment](AI/deployment.md): backend-owned paired releases and recovery.

Current work, root causes and QA results belong in GitHub Issues/PRs, not README
phase logs. [Historical plans/reports](AI/archive/README.md) are reference only.
